# TW Chip Breakout Strategy

## Goal

Integrate a chip-driven breakout screen into the daily TW stock analysis flow.

Core idea adapted from the referenced PDF:

- Top-10 main-force buying is strong
- Foreign investors keep buying for N days
- Key broker / branch seats keep buying for N days
- Price breaks out from a consolidation platform

This strategy treats chips as the primary driver and uses the breakout as the timing trigger.

## Current integration

The daily quant candidate selection now supports a `chip breakout` bucket ahead of the existing revised / legacy ranking.

Priority order:

1. `chip_breakout`
2. `revised`
3. `legacy_watch`

If chip columns are missing, the flow safely falls back to the existing revised / legacy logic.

## Required optional columns

Place an enrichment file at:

- `data/tw_chip_snapshot.csv`

The refresh flow will merge it into `data/tw_listed_otc_stocks.csv` automatically when the file exists.

Supported column aliases:

- Top-10 main force strength:
  - `top10_main_force_buy_strength`
  - `top10_main_force_strength`
  - `top10_main_force_buy_ratio`
  - `top10_main_force_ratio`
  - `top10_buy_share_pct`
  - `top10_main_force_share_pct`
  - `top10_main_force_buy_rank`
  - `top10_main_force_rank`
  - `top10_main_force_net_buy`
  - `main_force_top10_net_buy`
- Foreign buy streak:
  - `foreign_buy_streak_days`
  - `foreign_net_buy_streak_days`
  - `foreign_buy_days`
- Broker / branch buy streak:
  - `branch_main_force_buy_streak_days`
  - `main_broker_buy_streak_days`
  - `broker_buy_streak_days`
  - `branch_buy_streak_days`
- Optional explicit breakout flag:
  - `platform_breakout`
  - `platform_breakout_flag`
  - `breakout_platform`
  - `breakout_of_platform`

## Default logic

The screen passes when all are true:

1. Platform breakout confirmed
2. Top-10 main-force signal is strong
3. `foreign buy streak >= 3` OR `branch buy streak >= 2`

If no explicit breakout flag is provided, the system derives breakout from OHLCV:

- prior 20-bar range is compressed
- latest close breaks above the prior platform high
- latest volume is above the recent average

## Example CSV

```csv
symbol,top10_main_force_buy_strength,foreign_buy_streak_days,branch_main_force_buy_streak_days,platform_breakout
2330,72,4,0,true
3017,66,0,3,true
```

## Notes

- This integration is intentionally optional because current TWSE / TPEx refresh endpoints do not yet populate branch-seat chip columns directly.
- Once `data/tw_chip_snapshot.csv` is generated by your own export or upstream ETL, the cloud workflow can consume it in the normal refresh flow.
